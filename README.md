# Hábitos Saudáveis

Aplicação web para registrar e acompanhar hábitos saudáveis no dia a dia. Projeto Integrador do curso técnico em Informática para Internet (ETEC Astor de Mattos Carvalho, 2025).

**Acesse online:** https://rayluansilva.github.io/habitos-saudaveis/

## Funcionalidades

- **Cadastro e login** de usuários
- **Registro de hábitos** e marcação do que foi cumprido no dia
- **Calendário** para acompanhar a constância
- **Progresso** geral e **conquistas** desbloqueadas conforme o uso
- **Configurações** de lembretes e **exportação** dos dados
- **Tema claro e escuro**
- Layout **responsivo** (celular, tablet e desktop)

Todos os dados ficam salvos no próprio navegador com `localStorage`, então a aplicação funciona sem servidor e sem banco de dados.

## Tecnologias

- HTML5 semântico
- CSS3 (Flexbox, variáveis CSS, layout responsivo)
- JavaScript puro (DOM, eventos, `localStorage`)
- Font Awesome (ícones)

## Páginas

| Arquivo | Função |
|---|---|
| `index.html` | Página inicial de apresentação |
| `login.html` | Cadastro e login |
| `home.html` | Painel com hábitos, calendário, progresso, conquistas e configurações |

## Como rodar localmente

Basta abrir o `index.html` no navegador. Não precisa instalar nada.
